## 2026-09-12 快手极速版首次运行

- 设备：`23a6524e`
- 包名：`com.kuaishou.nebula`
- 主页面：`com.yxcorp.gifshow.HomeActivity`
- 任务中心嵌入 `com.yxcorp.gifshow.HomeActivity`，独立收益页使用 `KwaiYodaWebViewActivity`。

实际链路：

1. 首次启动显示隐私协议“欢迎使用快手极速版”。隐私授权不自动同意，由用户处理。
2. 同意后显示新人奖励页“送你2元现金”，点击“立即领取”。
3. 领取后进入“可兑换2元”提现页。提现属于资金操作，自动化不点击，通过返回退出。
4. 返回任务中心后显示“专属登录奖励”，点击“去查看”进入“我的收益”。
5. 未登录时收益页仍显示金币和现金，但视频奖励标记为“未登录专属”。
6. 从任务中心返回时出现“真的要离开吗”，点击“离开”后回到视频首页。

自动化结论：

- 首次协议和新人奖励只在启动页不符合预期时识别，不加入日常循环检测。
- 登录作为独立前置流程处理；已登录或已经位于首页时直接跳过。
- 提现、协议授权和第三方授权确认不自动执行。
- 低频弹窗只在页面未推进或恢复首页时，复用当前 UI 树快速匹配。
- 正常浏览不截图、不跑 OCR；连续失败达到诊断阈值后才保存完整证据。

## 2026-09-13 快手视频观看节奏核对

- 近期结构化日志中，多条普通视频在约 3.92、4.08、5.96、4.30、4.00 和 5.03 秒后切换，用户观察到的快速划动属实。

- 明确广告和疑似广告采用独立短时分布且禁止互动。疑似广告表示视频流存在但关键分类标记均未命中，日志与明确广告分开记录。
- 视频分类已从公共插件拆为独立分类器，稳定机器类型负责分支，中文内容类型只用于展示。
- 设备恢复后完成 3 条定向复验，轮次 `a50ffbf103884da89f4b13125cdea653`：共完成 3 条，识别 1 条广告和 2 条普通视频，未执行关注、点赞、评论或主页浏览。

- 第 2、3 条分别通过“快手全屏内容”和“快手作品文案”确认为普通视频，采用常规观看模式，总停留 20.36 秒和 25.04 秒；其中分类后继续停留 14.94 秒和 21.08 秒。
